# Portfólio Web - Página Pessoal

Este projeto consiste no desenvolvimento de uma Página Pessoal (Portfólio Web) responsiva, com informações reais, desenvolvida em duas versões distintas para fins comparativos entre frameworks CSS:
* **Versão Bootstrap 5**: Construída com o framework Bootstrap (v5.3.3).
* **Versão Bulma CSS**: Construída com o framework Bulma (v1.0.2).

O projeto está publicado e acessível no GitHub Pages através do link abaixo:

* **Link da Aplicação**: [https://gustavo-alessandro.github.io/pagina-pessoal/](https://gustavo-alessandro.github.io/pagina-pessoal/)

## Conteúdo e Seções do Portfólio

O portfólio reúne trajetórias acadêmicas e profissionais reais do desenvolvedor **Gustavo Alessandro**, distribuídas nas seguintes seções:

* **Página Inicial de Seleção (`/index.html`)**: Landing page neutra que permite ao visitante escolher qual das duas versões do framework deseja visualizar.
* **Cabeçalho e Apresentação**: Foto de perfil, informações acadêmicas resumidas, links diretos de contato e botões para GitHub/LinkedIn.
* **Sobre**: Trajetória pessoal e acadêmica.
* **Habilidades**: Lista de tecnologias organizadas por tags e barras de progresso que indicam o nível de domínio técnico.
* **Experiência Profissional**: Detalhes sobre a atuação real no desenvolvimento de Projetos.
* **Projetos em Destaque**: Cards com links diretos para repositórios e demonstrações funcionais.
* **Certificações**: Cursos extracurriculares e certificações intermediárias da graduação.
* **Interesses**: Áreas de interesse técnico e atividades pessoais.
* **Contato**: Canais de comunicação direta (e-mail, telefone, GitHub, LinkedIn e Instagram).

## Funcionalidades e Recursos Técnicos

### 1. Tema Claro e Escuro (Dark Mode)
* Ambas as versões possuem alternância dinâmica de tema executada via JavaScript nativo.

### 2. Responsividade e Experiência de Uso
* **Layout Fluido**: Adaptação para dispositivos móveis, tablets e desktops através dos sistemas de grid/flexbox nativos de cada framework.
* **Menu Mobile**: Funcionalidade interativa para exibição e ocultação do menu hamburguer em telas menores.
